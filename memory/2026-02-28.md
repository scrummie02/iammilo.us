## Key Technical Findings

- In bash scripts/subshells: must NOT set `GOG_KEYRING_PASSWORD=""` — let it inherit
- `while read` loop stdin conflict: use `read -u3` + `3< file` to avoid gog consuming loop input
- Nextcloud WebDAV mount hangs Python subprocess file reads when server is unavailable
