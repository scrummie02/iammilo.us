### n8n Workflow Fixes — Daily Fact & Daily Dad Joke
- Both workflows had broken MySQL nodes (credential issue + schema mismatch with `content_hash`)
- **Fix 1 attempted:** Replace MySQL with `fs`-based JSON file — BLOCKED by n8n sandbox (`fs` module disallowed in Code nodes)
- **Fix 2 applied:** Replace with `$getWorkflowStaticData('global')` — n8n's native persistent storage, no sandbox restrictions
- Check DB node: uses `crypto.createHash('sha256')` + `$getWorkflowStaticData` to check if hash seen before
- Mark Sent node: pushes hash into `staticData.sentHashes[]`, capped at 500 entries
- Both workflows patched via API (`AjAjjxb9j94iE0JK` = Daily Fact, `m7EMbjBDyv2MMCBo` = Daily Dad Joke)
- **Key lesson:** n8n Code nodes block `fs`, `child_process`, and most Node.js built-ins. Use `$getWorkflowStaticData` for persistence.
